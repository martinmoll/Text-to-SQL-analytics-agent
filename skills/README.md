# Skills

Markdown playbooks that guide the agent's reasoning. This is the highest-leverage component — Anthropic's accuracy went from 21% to 95%+ by adding skills.

- `knowledge.md` — Top-level router: maps question domains to reference docs
- `analyst.md` — Procedural playbook (clarify → resolve → find → query → review → deliver)
- `references/` — Domain-specific reference documents
